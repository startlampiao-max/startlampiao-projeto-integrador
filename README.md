# StartLampião

Projeto Integrador desenvolvido para a criação de uma aplicação web de delivery multi-restaurantes.

## Objetivo

O StartLampião tem como objetivo conectar clientes, restaurantes e serviços de entrega em uma única aplicação.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

- Área do Administrador
- Gerenciamento de pedidos
- Gerenciamento de entregadores
- Integração com WhatsApp
- Integração com Google Maps

### Execução do backend

1. Instalar o Node.js e o MySQL.
2. Clonar o repositório.
3. Acessar a pasta backend.
4. Executar npm install.
5. Criar o arquivo .env com base no .env.example.
6. Configurar as credenciais do banco de dados MySQL.
7. Preparar as tabelas utilizando o script SQL
   disponibilizado na pasta database.
8. Executar npm start.

O servidor utiliza a porta 3000 por padrão.
