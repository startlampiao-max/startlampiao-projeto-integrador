# StartLampião

Projeto Integrador desenvolvido para a criação de uma aplicação web de delivery multi-restaurantes.

## Objetivo

O StartLampião tem como objetivo conectar clientes, restaurantes e serviços de entrega em uma única aplicação.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Áreas do sistema

- Área do Cliente
- Área do Restaurante
- Área do Administrador
- Gerenciamento de pedidos
- Gerenciamento de entregadores
- Integração com WhatsApp
- Integração com Google Maps

## Organização do desenvolvimento

O projeto será desenvolvido de forma colaborativa utilizando Git e GitHub.

Cada integrante trabalhará em sua própria branch, permitindo o acompanhamento das contribuições individuais durante o desenvolvimento.
